add_messages — 메시지 전용 리듀서

리듀서 없음 = 덮어쓰기

[질문1]
  → 노드가 [답변1] 반환
  → [답변1]

❌ 질문이 사라진다

add_messages = 이어붙이기

[질문1]
  → 노드가 [답변1] 반환
  → [질문1, 답변1]

✅ 대화가 쌓인다
class State(TypedDict):
    messages: Annotated[list, add_messages]   # ← 이 한 줄이 전부

첫 멀티턴 챗봇

class State(TypedDict):
    messages: Annotated[list, add_messages]

def chatbot(state: State):
    response = llm.invoke(state["messages"])   # 대화 전체를 넘긴다
    return {"messages": [response]}          # 답변만 반환 → 뒤에 이어붙음

builder = StateGraph(State)
builder.add_node("chatbot", chatbot)
builder.add_edge(START, "chatbot")
builder.add_edge("chatbot", END)
graph = builder.compile()
잘 되지만 매 턴 state["messages"]를 직접 들고 다녀야 합니다 → 다음 장에서 자동화

체크포인터 — 대화를 자동으로 기억

from langgraph.checkpoint.memory import MemorySaver

graph = builder.compile(checkpointer=MemorySaver())   # ← 이 한 줄이 전부

config = {"configurable": {"thread_id": "user-1"}}      # 대화방 번호

graph.invoke({"messages": [{"role":"user","content":"내 이름은 김철수야."}]}, config)
r = graph.invoke({"messages": [{"role":"user","content":"내 이름이 뭐라고?"}]}, config)

print(r["messages"][-1].text)   # → 김철수님이요! ✅
새 질문만 넣었는데도 기억합니다. 앞 대화는 체크포인터가 알아서 꺼내 붙여줬습니다.

thread_id = 대화방 번호

📁 thread_id = "user-1"

[질문1, 답변1, 질문2, 답변2, …]

📁 thread_id = "user-2"

[ … 완전히 별개의 대화 … ]

  • 사용자 ID, 세션 ID, UUID — 구분만 되면 아무 문자열이나 OK
  • 같은 값 → 대화가 이어짐 / 새 값 → 새 대화 시작
  • MemorySaver는 램에 저장 → 프로그램 끄면 사라짐
  • 영구 저장은 SqliteSaver 등 (오늘은 불필요)

rag_bot — 검색해서 답하는 노드

def rag_bot(state: State):
    question = state["messages"][-1].text                       # ① 마지막 질문
    context  = "\n".join(d.page_content for d in retriever.invoke(question))   # ② 검색

    prompt = f"""아래 자료만 근거로 질문에 답하세요.
자료에 없으면 "자료에서 찾을 수 없습니다"라고 답하세요.

[자료] {context}
[질문] {question}"""                                     # ③ 프롬프트 조립

    return {"messages": [llm.invoke(prompt)]}                  # ④ 답변 반환
핵심 — 입출력 모양이 chat_bot과 똑같습니다. messages를 받아 messages를 반환하므로, 갈아 끼우듯 분기할 수 있습니다.

def route(state: State):
    q = state["messages"][-1].text

    # LLM에게 분류를 맡긴다
    a = llm.invoke(
        ROUTER_PROMPT.format(question=q)
    ).text.strip().lower()

    return "docs" if "docs" in a else "chat"

class State(TypedDict):
    messages: Annotated[list, add_messages]

# ② 봇 = 함수 (messages 받아 messages 반환)
def some_bot(state):  return {"messages": [llm.invoke(state["messages"])]}

def route(state):    return "docs" or "chat"

# ④ 조립 + 기억
builder.add_conditional_edges(START, route, {"chat": "chat_bot", "docs": "rag_bot"})
